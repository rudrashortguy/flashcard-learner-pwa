# CardFlash PWA

Spaced repetition flashcard app for mastering languages, exams, and concepts.

### Features
- SRS algorithm simulation
- Deck import/export
- Keyboard shortcuts
- Progress stats

### Tech Stack
- **Vite** & **TypeScript**
- **Workbox / Vite PWA Plugin** for offline capabilities
- **IndexedDB & LocalStorage** for persistent state

### Getting Started
```bash
npm install
npm run dev
```
